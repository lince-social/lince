# Lince

Tool for registry, interconnection and automation of Needs and Contributions with open scope.

The documentation for the Lince tool is inside the app.


# Usage

> Hic sunt dracones.

You can download the latest release binary from the builds, or if you want to compile yourself:

```bash
cargo run
```
