# Lince

Tool for registry, interconnection and automation of Needs and Contributions with open scope.

The documentation for the Lince tool is inside the app.

# Usage

> Hic sunt dracones.

You can download the latest release binary from the builds, or if you want to compile yourself:

```bash
cargo run
```

Native plugins are developed in the [Lince plugins repository](https://github.com/lince-social/plugins).
To build and install them from source, clone it as `../plugins` alongside this checkout and follow its setup instructions.
