# Lince

Tool for registry, interconnection and automation of Needs and Contributions with open scope.

The documentation for the Lince tool is inside the app. This is the slopped version of Lince, also called Slopince, a proof-of-concept with barely functioning features. The general form has been understood, and it is being researched and developed in the codeberg [repo](https://codeberg.org/lince-institute/lince.git). The slopping of this will continue after v1.0.0, for short term usefulness (few years). This will eventually be abandoned until 2036 by the creator due to the real Lince being done, in that case you'll have a better tool.

This has been constructed/slopped 99% by one person, the real Lince should be a joined factor aiming for a bus factor of thousands of people.

# Usage

> Hic sunt dracones.

You can download the latest release binary from the builds, or if you want to compile yourself:

```bash
cargo run
```

# Workspace development

Workspace Stage 01 was built and tested while many other agents and builds were running on the same machine. Its recorded measurements and problems need another pass with workspace as the only active development/build/test workload. The owner will finish the other agents' work before resuming workspace; future workspace implementation and testing use that isolated arrangement.

Before starting Stage 02, complete the [required isolated resumption check](institute/anicca/workspace/00-General.md#workspace-resumption-and-isolated-validation): review all Stage 01 findings and setup adjustments, rerun the relevant workflows, and establish fresh performance and behavior evidence. Preserve the original observations; resource contention is a possible influence, not an established explanation for every problem.
