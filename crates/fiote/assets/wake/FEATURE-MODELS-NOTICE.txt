These are feature extraction assets, not the separately trained openWakeWord
wake classifiers. Those classifiers have a separate noncommercial model
license and are not included.
Lince performs reference enrollment, matching, peak selection, timing, validation
and bounded streaming in Rust using tract. Python and ONNX Runtime are not used.
