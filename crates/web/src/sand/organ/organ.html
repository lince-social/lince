            Discovery
            If you run this Cell as a relay for others: a relay cannot read anything that passes through it — every connection is encrypted end to end — but it does observe IP addresses, connection times, and who dialled whom. That is exactly the trust this design elsewhere says nobody should have to extend, so the only honest mitigations are to not log it and to say so. Lince keeps no record of relayed connections. Each peer is capped at 8 concurrent connections so one of them cannot exhaust the machine.
