Trail

Trail mode lays one root's link tree out as an ordered path (physics off). Select a node there to mark it Done/Undo — next steps are set automatically. The tree needs depth: raise Tree depth above if it looks cut.

A preset buckets steps by quantity (a value 1 or range 3..10) or concept (@done) — writes follow the bucket: set-quantity or set-concept, shared with kanban columns.

Local physics
Node gravity

Weighs nodes by depth in the Trail root's tree: the root sinks (or floats) and each hop out gets lighter — records outside the tree weigh like leaves. Lighter nodes keep falling until their link tethers them, so the tree hangs like a mobile. Center forces stay on; charge/link soften. Uses the root and order kind from the Trail section.

Gestures

Click a node to open it in Record. Drag to move. Shift+drag node → node to link. Click an edge to select it, then Delete (or ✕ above) to unlink. Ctrl+Z undoes a link add/remove. Wheel zooms, background drag pans.
