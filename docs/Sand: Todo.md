A Todo is really important. If we don't even have a good Todo, Lince feels like it's only for complex workflows.

The Todo must have:

- [ ] Record CRUD.
- [ ] Time control: Pomodoro like.
- [ ] Keyboard movement.
- [ ] Hextech-like blob that feels alive and the user can customize it's physical properties and the colors. When the user finishes all the tasks the blob grows to occupy all the screen and becomes even more magical, then it dissipates. Giving the person a dopamine reward for finishing the tasks.
