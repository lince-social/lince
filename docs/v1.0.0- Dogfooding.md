Dogfooding means we use what we produce in the software world.

The first major version of Lince is going to be focused on using it for ourselves.
We plan to make workflows around TODOs, Finance and Transfer Proposals that are added because without it a v1 would be just a local tool. If we can connect between different instances of Lince (mine and yours), the todo+finance app becomes a way to spark new ways to relate.

The stuff for v1 then is for features we use daily: personal habits, work tasks, calculating our future resources, and using platforms for buying/selling items and services.
