Simulation still needs safe, editable proposals that compare changes against the user's data, can be shared for review, and are applied through normal checks after approval; broader Lingua declarations and control over timers, external responses, disk failures and crashes; more varied seeds, concurrent actions and independent correctness checks; complete transfers between Organs, blob contents saved with runs, and real tests of direct connections across NATs, relays and mailboxes. The Castle should grow with these capabilities, adding focused Cell and event editing, comparisons between runs, and links from Calendar items to their explanations. Projection work remains on additional filters and permitted viewers, time boundaries, larger workloads, and replacing older approximations where the shared runtime has coverage. Karma's authorized Program execution and the older recurrence tests also need completion. Record versions, history and transclusion should reuse the existing document machinery when proposals reach the editor. Restore during a run and finer cache invalidation should wait for a demonstrated need; persistent results and cached Calendar windows already cover ordinary restarts.
