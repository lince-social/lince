# Transfers: deferred phone tests

Phone hardware checks are deferred at the user’s request. Resume when the user is ready to connect the phone. Keep these results unverified until exercised on the device. Automated and desktop evidence is recorded in [the verification report](transfer-validation/2026-10-20-follow-up.md).

- [ ] **V1 — Actual Android location.** Use an isolated test profile with mock providers removed. Allow approximate OS access up to 12 minutes for a fresh fix, then precise access up to 3 minutes. Record provider, age and accuracy without publishing private coordinates. Link an ordinary address Record into Transport and compare exact, user-configured 3000 m and excluded audiences in at most four Linces. OS permission and audience precision are separate: area-only viewers receive generalized geometry and excluded viewers receive none. A missing fix leaves that branch unverified. Reuse existing Stop/revocation evidence unless device behavior exposes a failure.
- [ ] **V2 — Background sharing, power and thermal behavior.** Combine with V1 in one roughly 30-minute session covering idle baseline, active/background sharing and stopped idle. Keep brightness/network/power conditions stable; record charging state, callbacks, CPU/wakes and available battery/thermal counters. Require one service, bounded cadence and acquisition ending on Stop/expiry without late resurrection. Report actual deltas without projecting all-day battery life. Restore original permissions, providers, location and awake settings.
- [ ] **V3 — Android map and accessibility.** Build/install the current isolated test APK. In one short pan/pinch sequence verify that ordinary zoom fetches missing street detail automatically, shows progress/received bytes and reuses cached data offline. Browsing must require no numerical detail input, area drawing or prior download action. Check configured sources/offline mode, saving an area at the current view detail, visible search/routing controls, touch scrolling through provider controls, cancellation and identity changes clearing private drafts. Make one large-text/RTL/readability pass through map, trust and visibility controls; check theme colors and idle map redraw. Measure device GPU completion/presentation only where exposed and identify unmeasured stages. No resize matrix, repeated map reopening, iOS or globe work.
