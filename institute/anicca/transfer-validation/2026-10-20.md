## Corrections made during verification

- K1 originally tried changing a Transfer's quantity directly, then discarding a linked child. Both correctly failed their revision/lifecycle guards. The test now withdraws the child's open promises with `ReviseTransferDraft`. Adding a child legitimately advances the parent's signed revision, so the test checks the original fact's hash, payload and signature plus unchanged contribution terms instead of incorrectly demanding a fixed parent revision number.
- K2 now explicitly checks that ordinary data reactions do not create repeated Transfers. Invitation acceptance advances the child's revision and invalidates earlier agreement; the test requires fresh current agreement instead of expecting automation to reuse old consent. Its no-receipt assertion now reads the actual `transfer_occurrence_claim_event` table.
- K3's fixture now configures each cell's Organ transport signer separately from its Person signer. The new Transfer scenario uses `export_sync_page` / `receive_sync_batch`, which carry identity evidence and Transfer replication, instead of copying raw operations without the required identity context. It no longer adds an unnecessary laptop edit after synchronization: the phone's update alone must trigger the authorized executor. It checks equal child UIDs and zero quarantined evidence.
- The mobile automation entry point could overwrite an existing Karma draft. It now refuses a different incoming draft with an actionable message while preserving the existing one. The automation test exercises that guard. Existing persistence and lock/recovery tests now also carry a private Karma draft through those boundaries.

The runtime change in this pass is the mobile draft-preservation guard. Other code edits correct or strengthen test fixtures and assertions. No migration or checksum entry was changed in this pass. The source scan found no active `RefreshStockPolicy`, `refresh-stock-policy`, `StockPolicy`, `mod stock` or `stock_policy` matches in the engine/interface/mobile/nucleus code searched.
