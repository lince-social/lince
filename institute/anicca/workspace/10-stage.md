# 10 — Dimensioned sketches and exact CAD

Finish able to design a precise bracket or mounting part for an authored place, change dimensions and keep valid source/history, mounts and exchange outputs coherent. Failed features remain repairable and cannot destroy the last accepted solid.

## Required workflow milestones

- [ ] **10.M01.** Create a native dimensioned sketch, extrude it, cut a hole and instance the bracket in a room/assembly. Change a dimension through the same native/programmatic accepted command and inspect remaining DOF/conflicts.

- [ ] **10.M02.** Retain the Rust-first ezpz/mesh prototype, then select an exact geometry adapter by the named bake-off. Show supported tolerance/operation/loss status; a successful prototype is not a claim of exact CAD.

- [ ] **10.M03.** Modify an upstream feature while a mount/downstream feature refers to a face/edge. Follow verified operation lineage and complete profile boundaries/holes; preserve source and expose ambiguity instead of guessing by nearest face.

- [ ] **10.M04.** Drag a parameter, compare useful preview with exact final geometry, export/import the supported STEP subset and recover from failed Boolean, malicious geometry, cancellation or kernel crash. A second editor's conflicting feature draft stays recoverable.

- [ ] **10.M05.** Use normal selected-copy editing for a supported CAD-derived mesh variant. Keep the exact recipe and label the derived branch honestly when arbitrary mesh edits no longer satisfy the original constraints.

## Worked contract example

- [ ] **10.X01.** Validate each supported dimension/constraint in its declared units/tolerance after constructive reduction and residual solve. Residual checks alone do not establish rank, DOF, valid branch, exact topology or historical correspondence; implement the full named CAD proofs. Use this standalone illustrative acceptance example to refine the actual production API and regression; it is not an already implemented Lince interface or sufficient milestone evidence.

  ```rust
  fn normalized_residuals_pass(rows: &[(f64, f64)]) -> bool {
      !rows.is_empty()
          && rows.iter().all(|(residual, tolerance)| {
              residual.is_finite()
                  && tolerance.is_finite()
                  && *tolerance > 0.0
                  && residual.abs() / tolerance <= 1.0
          })
  }

  fn main() {
      assert!(normalized_residuals_pass(&[
          (0.0005, 0.001),
          (0.0001, 0.0002)
      ]));
      assert!(!normalized_residuals_pass(&[(0.002, 0.001)]));
      assert!(!normalized_residuals_pass(&[(0.0, 0.0)]));
  }
  ```
