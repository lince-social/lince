Take the location of Records, display them in a 2d map

Rebirth (docs/fable-improvement.md): location is `record.place` — the place Instinct (coordinates or address, with engine functions for distance and routing). The 2D map is a sand over a Protein like `source: record, where: within(place, <area>), include: promises` — no map-specific storage, no location logic in the frontend beyond drawing.
